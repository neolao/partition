## Project overview

Site statique permettant d'écrire une partition de musique dans le navigateur et d'en générer un PDF à imprimer. La partition peut être importée et exportée dans un format standard (MusicXML). Aucun backend : tout s'exécute côté client.

**Référence UX :** l'ergonomie de noteflight.com (saisie directe sur la portée, palette d'outils, lecture) sert d'inspiration pour l'éditeur.

**Stack:** Node.js 22 / TypeScript / Vite / Vitest / Biome
**Type:** frontend (site statique)

## Project language

Français — all documentation, backlog items, code comments, and other generated content for this project are written in français.

### Definition of Done

- [ ] Tests cover the nominal path, at least 2 edge cases, and the error path, and all pass (`npm test`)
- [ ] Lint exits 0 (`npm run lint`)
- [ ] The change was exercised for real at runtime, not only through tests
- [ ] No debug artifacts, dead code, or unused imports
- [ ] No hardcoded secrets — environment variables only

**Never present a result while tests are failing.** On a failure: diagnose, fix, re-run, up to 3 times; escalate only for an ambiguous requirement.
