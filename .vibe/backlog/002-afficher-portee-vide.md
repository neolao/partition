# Afficher une portée vide

## Description

Afficher une portée vide dans la page, rendue avec la librairie retenue par l'item 001. C'est la base visuelle de l'éditeur.

## Acceptance Criteria

- [ ] L'utilisateur voit une portée vide à l'ouverture du site.
- [ ] La portée reste lisible quand la fenêtre est redimensionnée.
- [ ] Le rendu s'affiche aussi dans le build statique (`npm run build` puis `npm run preview`).

## Notes

Dépend du choix de librairie de l'item 001.
