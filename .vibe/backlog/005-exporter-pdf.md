# Exporter la partition en PDF

## Description

Générer dans le navigateur un PDF imprimable de la partition, sans serveur.

## Acceptance Criteria

- [ ] L'utilisateur télécharge un PDF de la partition en un clic.
- [ ] Le PDF reproduit les notes et silences saisis, lisibles à l'impression en A4.
- [ ] Une partition longue est répartie sur plusieurs pages sans coupure au milieu d'une mesure.
- [ ] L'export d'une partition vide produit un message clair plutôt qu'un PDF vide.
